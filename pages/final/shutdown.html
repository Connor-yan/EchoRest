SESSION USAGE / FIELD TRACE
使用字段的最后一项

                

                
前三个字段由维护记录补全。使用字段另有一条追加记录，可继续解析它的来源指针。

                

                

                    
CURRENT SESSION MATCH / 当前会话匹配

                    

                    
USAGE FIELD 的最后一项来自本次登记引用的当前维护会话。系统把这次处理行为解释为该空间正在被使用，并用它补齐最后一个字段。

                    
可撤回当前会话对本次登记的使用证明。撤回后，USAGE FIELD 将失去这一项依据，本次公开写入随之终止。
